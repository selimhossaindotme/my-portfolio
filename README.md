# MD Selim Hossain — Developer Portfolio

A premium, modern developer portfolio website engineered with **Next.js 16 (App Router)**, **React 19**, **TypeScript**, **Tailwind CSS v4**, and **shadcn/ui** design patterns, inspired by modern Dribbble developer portfolios and custom radial lighting aesthetics.

---

## 🌟 Visual Architecture & Highlights

- **Aesthetic**: Deep atmospheric obsidian & slate backdrop with neon emerald (`#10b981`) and violet (`#8b5cf6`) ambient spotlights.
- **Signature Typography**: Modern sans-serif headings accented with elegant display serif italic keywords (*Sketch*, *Imagine*, *Amazing*, *project*).
- **Three-Way Theme System**: Fully integrated `Light`, `Dark`, and `System` modes powered by `next-themes` and CSS variables, with persistent storage and system theme auto-detection.
- **Tech Circuit & Radar Diagrams**: Interactive orbital tech radar and circuit connection nodes in the About and Tech Toolbox bento grids.
- **Infinite Marquee Ribbon**: Sleek glowing violet ribbon marquee showcasing technologies.
- **Project Showcase**: Production-level cards with mockup previews, verified implemented feature lists, code repository links, live demo buttons, and interactive architecture detail modals.
- **Interactive Terminal**: Live code sandbox tabs displaying backend controller logic, Zod validation schemas, and Express RBAC routing.
- **Interactive Contact Form**: Working validation, field checking, and submission feedback.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

### 4. Start Production Server
```bash
npm run start
```

## ⚙️ Configuration & Customization

All personal details, project descriptions, skills, social links, and coursework are centralized in a single configuration file:

👉 `src/data/portfolioData.ts`

To customize your email, GitHub link, project URLs, or stats, simply update this file and the entire portfolio updates dynamically.
